# ModernUI-GTNH - Player Changelog

This file is written for players. It is used by the in-game changelog, GitHub
Release notes and the CurseForge file page. The detailed developer history is
kept in `CHANGELOG.md`.

## [2.0.2] - 2026-11-28

### English

#### Highlights

- The settings screen has been cleaned up and returned to a simpler layout, so the most-used options are easier to find.
- The home page now has a colorful gradient title, clickable project links and a changelog you can scroll.
- Sliders have a cleaner ModernUI-style look, and you can type an exact value in the box on the right.
- The settings screen now scales with your screen resolution. The 2420x1668 layout keeps its original size.
- Fewer bundled font files means a smaller download. Bold text is generated automatically.

#### Fixed

- The changelog now shows only the language selected in Minecraft and wraps correctly inside its card.
- Text on the home page no longer runs past the card edges.
- The copyright line stays at the bottom of the home page.
- Smooth scrolling now keeps its momentum, so faster wheel movement scrolls farther.
- Forge startup warning screens are no longer hidden by the loading screen.
- The key-binding list keeps working with the mouse wheel after you search.
- Server MOTD/TPS options were removed from the client settings. MiniMOTD's own config is now the only MOTD source.

### 中文

#### 重点

- 设置界面重新整理，回到更简单的三栏布局，常用选项更容易找到。
- 主页加入了彩色渐变标题、可点击的项目链接，以及可以滚动的更新日志。
- 滑条换成了更清爽的 ModernUI 风格，右侧可以直接输入精确数值。
- 设置界面会跟随屏幕分辨率缩放；在 2420x1668 下保持原来的大小。
- 内置字体文件减少，模组体积更小；粗体文字会自动生成。

#### 修复

- 更新日志现在只显示 Minecraft 当前选择的语言，并且会在卡片内正确换行。
- 主页文字不再超出卡片边缘。
- 版权信息固定显示在主页底部。
- 平滑滚动保留了惯性，滚轮滚得越快，滚动距离越远。
- Forge 启动时的警告/询问界面不再被加载画面遮住。
- 按键列表在搜索过滤后仍然可以用滚轮滚动。
- 客户端设置中不再显示服务端 MOTD/TPS 选项，MOTD 统一由 MiniMOTD 自己的配置管理。
